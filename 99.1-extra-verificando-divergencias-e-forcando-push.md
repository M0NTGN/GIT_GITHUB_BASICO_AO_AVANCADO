# Seção Extra: Verificando divergências e forçando o push

## Verificar estado do repositório

```bash id="5a0z7y"
git status
```

Mostra o estado da branch atual e sua relação com o repositório remoto.

Exemplo:

```text
Your branch and 'origin/main' have diverged,
and have 1 and 1 different commits each
```

> **Diverged** = local e remoto possuem commits diferentes.

---

## Ver histórico visualmente

```bash id="qk8w1m"
git log --oneline --graph --decorate --all
```

Mostra o histórico de commits em formato gráfico, incluindo branches e referências remotas.

Útil para entender **onde os históricos divergiram**.

---

## Comparar commits locais e remotos

```bash id="2x5r7p"
git log origin/main..main
```

Mostra commits que existem **na branch local**, mas não em `origin/main`.

```bash id="h0g8pc"
git log main..origin/main
```

Mostra commits que existem **no remoto**, mas não na branch local.

### Regra mental

```text id="z8qfdm"
origin/main..main
→ só no local

main..origin/main
→ só no remoto
```

---

## Ver diferenças de conteúdo

```bash id="c1n0dv"
git diff origin/main main
```

Mostra diferenças de conteúdo entre a branch local e a versão remota.

> `git log` compara **commits**; `git diff` compara **conteúdo**.

---

## Forçar atualização do remoto

```bash id="p6w0qa"
git push --force-with-lease
```

Força o envio quando o histórico local foi **reescrito** com operações como:

```text
rebase
squash
fixup
reword
amend
```

> ⚠️ Pode substituir o histórico remoto. Use somente quando você sabe que deve reescrevê-lo.

### Por que não usar `git push --force`?

```text id="4xv3te"
--force
→ força sem verificar mudanças remotas

--force-with-lease
→ força apenas se o remoto ainda estiver como esperado
```

**`--force-with-lease` é a opção mais segura.**

---

## Fluxo para histórico reescrito

```text id="m5b5jl"
Rebase / fixup / squash
        ↓
git status
        ↓
git log --oneline --graph --decorate --all
        ↓
Verificar divergência
        ↓
git push --force-with-lease
```

### Regra mental

```text id="d3e5e0"
status → situação atual
log    → histórico/commits
diff   → diferenças de conteúdo
force  → substituir histórico remoto
```
