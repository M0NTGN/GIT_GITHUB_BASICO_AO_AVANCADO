# Seção 5: Análise e inspeção de repositório

### Git show

```bash
git show
```

Mostra os detalhes do **commit mais recente**, incluindo alterações realizadas.

```bash
git show <commit>
```

Mostra os detalhes de um commit específico.

### Git diff

```bash
git diff
```

Mostra alterações **não staged** em relação ao último commit.

```bash
git diff <branch>
```

Mostra as diferenças entre a branch atual e a branch indicada.

### Git shortlog

```bash
git shortlog
```

Exibe um resumo dos commits, agrupados por autor.
